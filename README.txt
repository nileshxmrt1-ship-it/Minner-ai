MINNER AI — Starter Demo

1. ZIP extract karo.
2. index.html ko Chrome browser mein open karo.
3. Message type karke Send dabao.
4. Voice input ke liye Speak dabao aur microphone permission allow karo.

Important:
- Ye front-end starter demo hai, abhi real AI model/API se connected nahi hai.
- Replies filhaal simple demo logic se aate hain.
- Chat history isi browser/device ke localStorage mein save hoti hai.
- Speech input browser support aur microphone permission par depend karta hai.
- Real AI connect karne ke liye secure backend banana hoga. API key ko HTML/JavaScript mein kabhi mat daalna.
